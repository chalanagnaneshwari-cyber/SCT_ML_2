# SkillCraft Technology – Machine Learning Internship

## Task 2: Customer Segmentation Using K-Means Clustering

### 📌 Project Overview
This project focuses on customer segmentation using the K-Means Clustering algorithm. The goal is to group customers into different segments based on their characteristics and spending behavior.

Customer segmentation helps businesses understand customer groups and develop targeted marketing strategies.

### 🎯 Objective
- Understand unsupervised machine learning.
- Explore and preprocess customer data.
- Apply the K-Means Clustering algorithm.
- Identify meaningful customer segments.
- Visualize and interpret the resulting clusters.

### 📊 Dataset
The project uses customer data containing features such as age, annual income, and spending score.

**Dataset:** Mall Customer Segmentation Dataset

**Source:** [Kaggle – Mall Customer Segmentation Data](https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python)

### 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

### ⚙️ Project Workflow
1. Load the customer dataset.
2. Explore the data and check for missing values.
3. Select relevant features for clustering.
4. Scale the features if required.
5. Use the Elbow Method to help determine the optimal number of clusters.
6. Train the K-Means Clustering model.
7. Assign customers to clusters.
8. Visualize the customer segments.
9. Interpret the characteristics of each cluster.

### 🤖 Algorithm Used
**K-Means Clustering** is an unsupervised machine learning algorithm that divides data points into a specified number of clusters. It groups similar data points together by minimizing the distance between points and their assigned cluster centers.

### 📈 Results
The K-Means model groups customers into distinct segments based on the selected features.

The visualizations help identify customer groups with different income levels and spending patterns.
